# Data Concierge — Historias Clínicas Protegidas

Front del prototipo funcional (Entregable 3). La documentación del proyecto vive en `docs/`.

## Requisitos

- Node.js 18.18 o superior (recomendado Node 20+)
- npm (viene incluido con Node.js)

## Instalación

1. Clona este repositorio.
2. Entra a la carpeta del front:

   ```bash
   cd frontend
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

## Cómo correrlo

Con las dependencias instaladas, desde la carpeta `frontend`:

```bash
npm run dev
```

Abre <http://localhost:3000> en el navegador. En la pantalla de ingreso aparecen tres
perfiles de demostración (administración, médico y auditor) que se seleccionan con un
clic, sin contraseña.
